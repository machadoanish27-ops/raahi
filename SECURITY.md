# Security Policy

## Supported Versions

Security fixes are considered for the latest revision on the default branch. This portfolio copy does not currently publish versioned releases.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting or Security Advisories for `machadoanish27-ops/raahi` when enabled. Include the affected component, reproduction steps, impact, and any suggested mitigation.

If private reporting is unavailable, contact the repository maintainer through the GitHub profile and avoid sharing secrets or exploit details publicly.

## Deployment Guidance

Keep `.env` files, database credentials, API tokens, model artifacts, and production logs out of commits. Replace all example secrets before running a deployed instance.
